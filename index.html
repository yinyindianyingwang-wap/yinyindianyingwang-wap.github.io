// 02 The List of 11

本月 11 部精选

从院线、流媒体、影展与经典库里筛出的 11 部，每部一句选片理由，覆盖不同心情与观影场景。

01

第十一封信

剧情 / 书信体 / 118 min / 8.9 分

一封迟到三十年的信，串起两代人的错过与和解，全片靠表演与留白撑起情绪，本月最稳的一部。

选片理由：台词克制，适合静下心看
02

沉默的边境

犯罪 / 悬疑 / 106 min / 8.6 分

边境小城的走私案，节奏紧、信息准，反转不靠巧合而靠人物选择，是近期少见的硬派犯罪片。

选片理由：全程无尿点，节奏教科书
03

第十一小时

战争 / 历史 / 142 min / 8.7 分

以停战前最后一小时为切口，群像叙事克制而有力量，战场之外的家庭戏同样扎实。

选片理由：大场面与小人物平衡得最好
04

她与她的海

爱情 / 治愈 / 103 min / 8.4 分

两位女性的海岛重逢，不煽情不狗血，海景摄影与配乐是隐形的第三主角。

选片理由：适合周末下午场
05

秋日长镜

文艺 / 家庭 / 96 min / 8.2 分

一个家庭三天的相处，用一个超长镜头串起，日常却暗流涌动，是本月最需要耐心的那部。

选片理由：长镜头的克制美学
06

老电影院

喜剧 / 怀旧 / 112 min / 8.1 分

县城最后一家老影院要拆了，放映员与常客们的故事，笑点密集但不廉价。

选片理由：笑中带泪的情怀之作
07

雪落无声

犯罪 / 东北 / 121 min / 7.9 分

东北小城的一桩旧案重启，方言与雪景构成独特质感，冷幽默是最大亮点。

选片理由：地域气质最浓的一部
08

极夜列车

科幻 / 惊悚 / 98 min / 7.8 分

密闭列车上的末日求生，设定不新但执行到位，中段一次反转值得回票价。

选片理由：设定简单的爽片选择
09

第十一扇窗

悬疑 / 心理 / 88 min / 8.3 分

独居女孩发现对面楼多了一扇窗，低成本密闭空间的恐惧感营造得非常成功。

选片理由：一个人看会更有感觉
10

晚风集市

纪录 / 市井 / 76 min / 8.0 分

跟拍一座城市的夜间集市，没有旁白只有声音，看完想去夜市走一圈。

选片理由：声音设计值得单独听
11

第十一页

动画 / 奇幻 / 94 min / 8.5 分

一本会自己续写的小说，每一页打开都是新世界，视觉想象力本月最佳。

选片理由：想象力与美术双在线
